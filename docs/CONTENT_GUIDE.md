# Content Guide

## Career 추가
`data/site-data.json`의 `career` 배열에 항목을 추가합니다.

필드 예시:

```json
{
  "company": "회사명",
  "period": "2026.01 — 2026.12",
  "role": "직무",
  "location": "Seoul",
  "summary": "한 줄 설명",
  "responsibilities": ["업무 1", "업무 2"]
}
```

## Experience 추가
`experience` 배열에 프로젝트성·단기성 경험을 추가합니다.

## Project 추가
`projects` 배열에 항목을 추가하고, 상세 원문은 `content/projects/프로젝트명.md`에 기록합니다.

## Art 추가
`art` 배열과 `content/art/`를 사용합니다.

## Writing 추가
`writing` 배열과 `content/writing/`를 사용합니다.

## 원칙
- 확인되지 않은 날짜나 성과 수치를 만들지 않습니다.
- 회사 내부 정보나 민감한 클라이언트 정보는 공개 전 삭제/비식별화합니다.
- 실제 작업 이미지의 공개 권한을 확인합니다.
