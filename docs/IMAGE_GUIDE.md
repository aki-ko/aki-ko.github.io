# Image Guide

## 권장 구조

```text
assets/images/projects/[slug]/
  cover.jpg
  001.jpg
  002.jpg
  detail-001.jpg
  process-001.jpg
```

## 권장 포맷
- 사진: JPG 또는 WebP
- 투명 배경 그래픽: PNG 또는 WebP
- 단순 아이콘: SVG
- GIF는 꼭 필요한 경우만 사용

## 권장 크기
- 긴 변 기준 1800–2400px 정도를 기본으로 사용
- 한 장당 가급적 1–2MB 이하로 최적화
- 원본은 Google Drive 등 별도 아카이브에 보관

## 파일명
영문 소문자와 하이픈 권장.

예: `2026-hospiup-bus-shelter-001.jpg`
