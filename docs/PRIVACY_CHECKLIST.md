# Privacy Checklist

공개 GitHub 저장소에 push하기 전에 확인하세요.

- [ ] 전화번호 공개 여부 결정
- [ ] 이메일 철자 확인
- [ ] 회사 내부 서버 경로 제거
- [ ] 병원·클라이언트의 미공개 자료 제거
- [ ] 환자·고객 개인정보가 포함된 이미지 제거
- [ ] 저작권/초상권이 확인되지 않은 이미지 제거
- [ ] 광고 심의 전/내부 검토용 시안 공개 가능 여부 확인
- [ ] 개인 주소·주민번호·계좌 등 민감정보가 없는지 확인

`data/private/`는 `.gitignore` 처리되어 있습니다.
