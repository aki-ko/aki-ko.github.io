# Project Structure

```text
goyoonji-portfolio/
├── index.html
├── css/
├── js/
├── data/
│   ├── site-data.json
│   └── private/
├── content/
│   ├── projects/
│   ├── art/
│   └── writing/
├── assets/
│   ├── images/
│   ├── video/
│   └── documents/
├── docs/
└── .github/
```

## 역할

- `index.html`: 메인 화면 구조
- `css/`: 디자인 시스템 및 반응형 레이아웃
- `js/main.js`: JSON 데이터를 불러와 화면에 렌더링
- `data/`: 구조화된 공개 데이터
- `data/private/`: 공개 Git 저장소에 올리지 않을 데이터
- `content/`: 장문 원문·프로젝트 노트
- `assets/`: 이미지·영상·문서
- `docs/`: 관리 가이드
